**Card** — the base warm-white surface for grouping content. Compose everything else inside it.

```jsx
<Card>
  <h3>Catalogue quality</h3>
  <p>Product data and channel readiness.</p>
</Card>

<Card interactive padding={20}>…</Card>
```

`padding` (px) and `interactive` (hover lift) are the only knobs. No colored-left-border variants — keep cards clean.
