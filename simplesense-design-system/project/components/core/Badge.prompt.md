**Badge** — compact status/category pill for table cells, list rows and metric tiles.

```jsx
<Badge tone="success">Ready</Badge>
<Badge tone="warning">Review</Badge>
<Badge tone="danger" dot>Blocked</Badge>
<Badge tone="primary" variant="outline">Synced</Badge>
```

Tones: `neutral` `primary` `success` `warning` `danger` `clay`. `variant="outline"` for a lighter treatment; `dot` adds a leading status dot.
